# panel_cutting

[![CI](https://github.com/TalBkzt/panel_cutting/actions/workflows/ci.yml/badge.svg)](https://github.com/TalBkzt/panel_cutting/actions/workflows/ci.yml)

Раскрой листовых материалов (ЛДСП, МДФ, фанера) для форматно-раскроечных станков на чистом Dart.
Без зависимостей, работает во Flutter, на сервере и в CLI.

Это движок раскроя из [Instrumental-M](https://github.com/TalBkzt/Instrumental-M-releases) —
программы учёта заказов для мебельных цехов, — вынесенный в отдельный пакет.

## Что умеет

- **Гильотинная раскладка.** Каждый рез идёт от края до края заготовки, поэтому любую раскладку
  можно повторить на форматнике. 6 правил разбиения остатка × 3 правила выбора места × 5 порядков
  деталей.
- **MaxRects.** Плотнее на смешанных списках деталей, но раскладка не всегда режется прямыми резами.
- **Карта резов с учётом пропила.** По готовой раскладке строит порядок резов: что отрезать первым,
  где поставить упор, что получится с каждой стороны пилы — деталь, заготовка, обрезок или опилки.
  Из всех возможных порядков выбирает тот, где меньше резов и крупнее деловые обрезки. Пропил
  считается физически: зазор шире пилы — это полоса материала, которую надо отрезать отдельно.
- **Сравнение раскладок.** Больше деталей → меньше листов → больше площади → меньше резов →
  крупнее обрезки.
- **Поиск.** `searchLayouts` перебирает рандомизированные раскладки (GRASP) и отдаёт поток всё более
  удачных вариантов, пока его не остановят.
- **Уплотнение.** `consolidateSheets` пытается убрать последний лист, раскидав его детали по
  пустым местам на предыдущих.
- Детали с направлением текстуры не поворачиваются (`canRotate: false`).

## Установка

Пакет пока не опубликован на pub.dev:

```yaml
dependencies:
  panel_cutting:
    git: https://github.com/TalBkzt/panel_cutting
```

## Пример

```dart
import 'package:panel_cutting/panel_cutting.dart';

void main() {
  const parts = [
    Part('Боковина', width: 720, height: 560, quantity: 8, canRotate: false),
    Part('Полка', width: 564, height: 520, quantity: 6),
    Part('Фасад', width: 716, height: 396, quantity: 8, canRotate: false),
  ];

  final result = packGuillotine(parts, sheetWidth: 2800, sheetHeight: 2070, kerf: 4);
  print('${result.sheetCount} листа, заполнение ${(result.utilization * 100).round()}%');

  for (final step in result.sheets.first.cuttingSteps()!) {
    print('${step.cut.orientation.name} рез на ${step.cut.markOffset} мм');
  }
}
```

Полный пример с поиском и печатью карты резов — в [example/main.dart](example/main.dart):

```bash
dart run example/main.dart
```

## Как это устроено

| Файл | Что внутри |
|---|---|
| [`guillotine.dart`](lib/src/guillotine.dart) | Гильотинный упаковщик одного листа и раскладка по листам |
| [`max_rects.dart`](lib/src/max_rects.dart) | MaxRects: три эвристики на каждый лист, побеждает самая плотная |
| [`cutting_guide.dart`](lib/src/cutting_guide.dart) | Построение карты резов по готовой раскладке |
| [`layout_quality.dart`](lib/src/layout_quality.dart) | Оценки: число резов, длина пропила, обрезки, нижняя граница листов |
| [`search.dart`](lib/src/search.dart) | Итеративный поиск, работает в текущем изоляте и не блокирует UI |
| [`consolidation.dart`](lib/src/consolidation.dart) | Перенос деталей с последнего листа в пустоты |

**Пропил в упаковщиках.** Каждая деталь упаковывается увеличенной на ширину пилы в лист, увеличенный
на столько же. Так между любыми двумя деталями гарантированно остаётся пропил, а у края листа место
не теряется.

**Карта резов.** Строится не во время упаковки, а по итоговым координатам. Поэтому она работает для
любого упаковщика и для раскладки, которую оператор поправил руками. Задача решается рекурсивно:
для области перебираются все прямые резы, которые не задевают детали, а результаты подобластей
мемоизируются. Если раскладка слишком большая, поиск переходит на первый допустимый рез, так что
время работы ограничено.

Алгоритмы упаковки основаны на J. Jylänki, *A Thousand Ways to Pack the Bin* (2010).

## Тесты

```bash
dart test
```

69 тестов, в том числе проверки инвариантов на сотнях случайных заказов: детали не пересекаются и
не выходят за лист, между ними есть пропил, ни одна деталь не теряется, гильотинные раскладки всегда
режутся прямыми резами, карта резов точно покрывает лист.
